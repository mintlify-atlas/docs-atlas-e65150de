Claude Dev Kit is a framework that automates the complete implementation lifecycle of user stories using Claude Code. From BDD scenario generation through code writing, testing, quality gates, and final reporting — all 10 phases are orchestrated by a single skill command, with automatic time tracking throughout.

## What Claude Dev Kit automates

Run `/implement-us US-001` and the framework handles all of this for you:

<Steps>
  <Step title="Context validation & BDD">
    Phase 0 validates your tools and project setup. Phase 1 generates Gherkin scenarios from your user story's acceptance criteria.
  </Step>
  <Step title="Planning & implementation">
    Phase 2 produces a detailed implementation plan (with a human approval gate). Phase 3 writes the code guided by that plan and your active stack profile.
  </Step>
  <Step title="Testing & quality gates">
    Phases 4–6 generate unit tests, integration tests, and BDD step definitions. Phase 7 validates Pylint score, cyclomatic complexity, maintainability index, and coverage.
  </Step>
  <Step title="Documentation & final report">
    Phase 8 updates docstrings and architecture docs. Phase 9 generates a complete implementation report with time metrics and quality gate results.
  </Step>
</Steps>
