This example shows how Claude Dev Kit's `/implement-us` skill builds a **fullstack blog application** using the `flask-webapp` profile. The profile follows a Backend for Frontend (BFF) pattern with Jinja2 server-side rendering, Flask-WTF forms with CSRF protection, and five Jinja2 templates. The framework generates 43 tests covering route logic, form validation, and BDD scenarios — reaching 99% coverage with a Pylint score of 9.84/10.

## User story

```markdown
# US-056: Blog Application

As a web user
I want a blog application with a graphical interface
So I can create, read, edit, and delete posts
```

**Acceptance criteria:**

- View a list of existing posts

## Key code snippet

The `PostForm` uses Flask-WTF validators to enforce content requirements. Spanish error messages are set directly on each validator:

```python
# app/forms/post_form.py
from flask_wtf import FlaskForm
from wtforms import StringField, TextAreaField, SubmitField
from wtforms.validators import DataRequired, Length


class PostForm(FlaskForm):
    """Form for creating and editing blog posts."""

    title = StringField(
        'Título',
        validators=[
            DataRequired(message='El título es requerido')
        ],
        render_kw={'placeholder': 'Ingrese el título del post'}
    )

    content = TextAreaField(
        'Contenido',
        validators=[
            DataRequired(message='El contenido es requerido'),
            Length(min=10, message='El contenido debe tener al menos 10 caracteres')
        ],
        render_kw={'placeholder': 'Ingrese el contenido del post', 'rows': 10}
    )

    author = StringField(
        'Autor',
        validators=[
            DataRequired(message='El autor es requerido')
        ]
    )

    submit = SubmitField('Guardar')
```

The route uses `form.validate_on_submit()` to handle both GET (show empty form) and POST (validate and redirect) in a single function:

```python
# app/routes/blog.py
@blog_bp.route('/post/new', methods=['GET', 'POST'])
def post_create():
    """Create a new blog post."""
    form = PostForm()

    if form.validate_on_submit():
        post = Post(
            title=form.title.data,
            content=form.content.data,
            author=form.author.data
        )
        created_post = db.create(post)
        flash('Post creado exitosamente', 'success')
        return redirect(url_for('blog.post_detail', post_id=created_post.id))

    return render_template('post_form.html', form=form, mode='create')
```

The `base.html` template renders flash messages from all categories:

```html
{% with messages = get_flashed_messages(with_categories=true) %}
  {% if messages %}
    <div class="flash-messages">
      {% for category, message in messages %}
        <div class="alert alert-{{ category }}">{{ message }}</div>
      {% endfor %}
    </div>
  {% endif %}
{% endwith %}
```

<Tip>
Flask-WTF automatically adds CSRF tokens to all forms when `SECRET_KEY` is configured. The `form.hidden_tag()` call in `post_form.html` renders the hidden CSRF input. For testing, set `WTF_CSRF_ENABLED = False` in the test configuration to avoid CSRF token errors.
</Tip>
